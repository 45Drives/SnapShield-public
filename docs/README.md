# SnapShield documentation

These guides are for administrators who install and run SnapShield on their Samba file servers. Read them in this order.

1. [Installation](installation.md): set up the 45Drives repository, install Cockpit and run the guided setup wizard.
2. [Connecting Samba](connecting-samba.md): install the SnapShield Samba module, protect your shares and check the connection.
3. [Getting started](getting-started.md): first sign-in, connecting your shares, and what a detection looks like.
4. [Dashboard guide](dashboard.md): every page of the SnapShield node dashboard.
5. [Control Panel guide](control-panel.md): manage many SnapShield servers from one place (Enterprise).
6. [Licensing](licensing.md): Community and Enterprise, trials, and applying or moving a license.
7. [Upgrading](upgrading.md): move to a newer SnapShield release.
8. [Uninstalling](uninstalling.md): remove SnapShield or the Control Panel.
9. [Troubleshooting](troubleshooting.md): common problems, their causes and fixes.
10. [FAQ](faq.md): short answers to common questions.

## Day-to-day operation

- [Responding to alerts](responding-to-alerts.md): what to do when SnapShield raises an event.
- [Restoring files](restoring-files.md): recover affected files from snapshots, or quarantine them.
- [Bans and allowlists](bans-and-allowlists.md): unban clients, allowlist trusted ones and avoid false positives.
- [Honeyfiles](honeyfiles.md): set up decoy files that catch attackers early.
- [Fire drills](fire-drills.md): safely simulate ransomware to confirm detection works.
- [Routine checks](routine-checks.md): a daily, weekly and monthly health checklist.

Found a problem that these guides don't cover? [Open a bug report](https://github.com/45Drives/SnapShield-public/issues/new/choose).
