# SnapShield documentation

These guides are for administrators who install and run SnapShield on their Samba file servers. Read them in this order.

1. [Installation](installation.md): set up the 45Drives repository, install Cockpit and run the guided setup wizard.
2. [Getting started](getting-started.md): first sign-in, connecting your shares, and what a detection looks like.
3. [Dashboard guide](dashboard.md): every page of the SnapShield node dashboard.
4. [Control Panel guide](control-panel.md): manage many SnapShield servers from one place (Enterprise).
5. [Licensing](licensing.md): Community and Enterprise, trials, and applying or moving a license.
6. [Upgrading](upgrading.md): move to a newer SnapShield release.
7. [Uninstalling](uninstalling.md): remove SnapShield or the Control Panel.
8. [Troubleshooting](troubleshooting.md): common problems, their causes and fixes.
9. [FAQ](faq.md): short answers to common questions.

Found a problem that these guides don't cover? [Open a bug report](https://github.com/45Drives/SnapShield-public/issues/new/choose).
