## Check the documentation first

- [Installation](docs/installation.md)
- [Troubleshooting](docs/troubleshooting.md)

## Questions and discussion

Ask how-to questions, share setups and get help from other users and the 45Drives team on the [45HomeLab Forum](https://forum.45homelab.com/).

## Community users

- **Questions:** the [45HomeLab Forum](https://forum.45homelab.com/).
- **Bugs:** [open a bug report](https://github.com/45Drives/SnapShield-public/issues/new/choose). Search [existing issues](https://github.com/45Drives/SnapShield-public/issues?q=is%3Aissue) first; if yours is already there, add a 👍 or any new details to it.
- **Ideas:** [request a feature](https://github.com/45Drives/SnapShield-public/issues/new/choose).

Community support is best effort. There is no guaranteed response time.

## Enterprise customers

Contact 45Drives at **[info@45drives.com](mailto:info@45drives.com)**. Include your SnapShield version, operating system and a description of the problem. You can also open a GitHub issue, but don't put private details in it — issues are public.

## Security issues

Never in a public issue. See [SECURITY.md](SECURITY.md).

## Before you post logs

Issues are public. Remove hostnames, IP addresses, usernames, share paths and license keys from anything you paste.
